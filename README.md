# Netflix-Dashboard

An interactive Power BI dashboard built to analyze Netflix titles, streaming trends, content distribution, and ratings. This project explores dataset patterns to uncover insights regarding movie vs. TV show ratios, genre popularity, release trends over the years, and regional content distribution.

---

## 📊 Project Overview
The goal of this project is to transform raw Netflix catalog data into a clean, interactive, and visually compelling reporting tool. The dashboard helps stakeholders quickly digest viewing metrics, content ratings, and catalog growth trends through dynamic filtering and drill-downs.

---

## 🚀 Key Features & Insights
* Content Mix Analysis: Visualizes the exact proportion of Movies vs. TV Shows available on the platform.
* Release Year Trends: Tracks how content additions have scaled across different decades.
* Rating Breakdown: Categorizes titles by maturity and audience ratings (e.g., TV-MA, PG, R).
* Geographical Distribution: Highlights top-producing countries contributing to the Netflix catalog.
* Interactive Filtering: Allows users to slice data dynamically by genre, release year, and content type.

---

## 🛠️ Tools & Technologies Used
* Power BI: Data modeling, DAX measures, Power Query transformations, and interactive dashboard design.
* Power Query: Data cleaning, handling null values, and formatting text/date columns.
* GitHub: Version control and project documentation.
